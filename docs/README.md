# Documentação do Projeto Conversa Apoiada 📚

Bem-vindo à pasta de documentação técnica do **Conversa Apoiada** (*Afasia da Cuca*).

Aqui você encontra todos os detalhes de arquitetura, fluxo de telas, modelo de banco e guia prático de desenvolvimento:

1. [**Arquitetura e Tecnologias**](./arquitetura-e-tecnologias.md) — Visão geral da stack (Next.js 14, React 18, TypeScript, Prisma, Web Speech API) e princípios de design para idosos com afasia.
2. [**Estrutura de Pastas e Módulos**](./estrutura-de-pastas-e-modulos.md) — Mapeamento detalhado de arquivos, componentes modulares e fluxo da Home.
3. [**Modelagem do Banco de Dados**](./banco-de-dados.md) — Esquema Prisma com tabelas simples de categorias, itens e deploy na Vercel com PostgreSQL.
4. [**Guia de Desenvolvimento e SSH**](./guia-de-desenvolvimento.md) — Como rodar localmente, comandos úteis e fluxo Git com SSH pessoal.
5. [**Proposta: prancha por fotos**](./proposta-prancha.md) — Nova tela `/prancha` baseada na entrevista com a família, modo família com câmera e proteção das rotas de itens (em revisão).
